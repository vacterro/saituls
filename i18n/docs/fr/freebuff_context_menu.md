Menu contextuel Freebuff

Add_Freebuff_Context_Menu.reg
  Ajoute 'Ouvrir avec Freebuff' :
  - Clic droit sur un dossier
  - Clic droit sur un espace vide dans un dossier

La commande lancée :
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  Supprime les entrées.
