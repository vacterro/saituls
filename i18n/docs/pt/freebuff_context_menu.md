Menu de contexto Freebuff

Add_Freebuff_Context_Menu.reg
  Adiciona 'Abrir com Freebuff':
  - Clique direito em uma pasta
  - Clique direito em um espaço vazio dentro de uma pasta

O comando inicia:
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  Remove as entradas.
