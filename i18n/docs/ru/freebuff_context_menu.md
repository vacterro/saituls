Контекстное меню Freebuff

Add_Freebuff_Context_Menu.reg
  Добавляет пункт «Открыть с помощью Freebuff»:
  - Правый клик по папке
  - Правый клик по пустому месту внутри папки

Запускается команда:
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  Удаляет записи.
