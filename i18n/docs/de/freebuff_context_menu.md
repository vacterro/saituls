Freebuff-Kontextmenü

Add_Freebuff_Context_Menu.reg
  Fügt 'Mit Freebuff öffnen' hinzu:
  - Rechtsklick auf einen Ordner
  - Rechtsklick auf leeren Platz in einem Ordner

Der Befehl startet:
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  Entfernt die Einträge.
