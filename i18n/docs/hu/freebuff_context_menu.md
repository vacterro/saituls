Freebuff helyi menü

Add_Freebuff_Context_Menu.reg
  'Megnyitás Freebuffbal' hozzáadása:
  - Jobb gombbal egy mappára kattintva
  - Jobb gombbal egy mappa üres helyére kattintva

Az elindított parancs:
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  Eltávolítja a bejegyzéseket.
