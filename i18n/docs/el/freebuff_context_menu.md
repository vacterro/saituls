Μενού περιβάλλοντος Freebuff

Add_Freebuff_Context_Menu.reg
  Προσθέτει το 'Άνοιγμα με Freebuff':
  - Δεξί κλικ σε φάκελο
  - Δεξί κλικ σε κενό χώρο μέσα σε φάκελο

Η εντολή που εκτελείται:
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  Αφαιρεί τις καταχωρίσεις.
