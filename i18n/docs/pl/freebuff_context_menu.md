Add_Freebuff_Context_Menu.reg
  Dodaje 'Otwórz za pomocą Freebuff':
  - Prawy przycisk myszy na folderze
  - Prawy przycisk myszy na pustym miejscu w folderze

cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe
