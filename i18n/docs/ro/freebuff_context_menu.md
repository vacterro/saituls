Meniu contextual Freebuff

Add_Freebuff_Context_Menu.reg
  Adaugă 'Deschide cu Freebuff':
  - Clic dreapta pe un folder
  - Clic dreapta pe un spațiu gol dintr-un folder

Comanda lansată:
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  Elimină intrările.
