Freebuff Context Menu

Add_Freebuff_Context_Menu.reg
  Adds 'Open with Freebuff' to:
  - Right-click on a folder
  - Right-click on empty space inside a folder

The command starts:
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  Removes the entries.
