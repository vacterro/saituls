Freebuff-contextmenu

Add_Freebuff_Context_Menu.reg
  Voegt 'Openen met Freebuff' toe:
  - Rechtsklik op een map
  - Rechtsklik op lege ruimte in een map

De opdracht start:
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  Verwijdert de vermeldingen.
