Freebuff-pikavalikko

Add_Freebuff_Context_Menu.reg
  Lisää 'Avaa Freebuffilla':
  - Hiiren oikea napsautus kansiossa
  - Hiiren oikea napsautus tyhjässä kohdassa kansion sisällä

Käynnistettävä komento:
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  Poistaa merkinnät.
