Контекстне меню Freebuff

Add_Freebuff_Context_Menu.reg
  Додає пункт «Відкрити за допомогою Freebuff»:
  - Правий клік по папці
  - Правий клік по порожньому місцю всередині папки

Запускається команда:
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  Видаляє записи.
