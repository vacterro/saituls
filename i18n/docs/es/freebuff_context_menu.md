Menú contextual de Freebuff

Add_Freebuff_Context_Menu.reg
  Añade 'Abrir con Freebuff':
  - Clic derecho en una carpeta
  - Clic derecho en un espacio vacío dentro de una carpeta

El comando inicia:
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  Elimina las entradas.
