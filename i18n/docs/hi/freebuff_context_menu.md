Freebuff संदर्भ मेनू

Add_Freebuff_Context_Menu.reg
  'Freebuff के साथ खोलें' जोड़ता है:
  - फ़ोल्डर पर राइट-क्लिक करें
  - फ़ोल्डर के अंदर खाली स्थान पर राइट-क्लिक करें

शुरू होने वाला कमांड:
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  प्रविष्टियाँ हटाता है।
