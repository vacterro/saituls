Menu konteks Freebuff

Add_Freebuff_Context_Menu.reg
  Menambahkan 'Buka dengan Freebuff':
  - Klik kanan pada folder
  - Klik kanan pada ruang kosong di dalam folder

Perintah yang dijalankan:
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  Menghapus entri.
