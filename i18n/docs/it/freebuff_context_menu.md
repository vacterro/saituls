Menu contestuale Freebuff

Add_Freebuff_Context_Menu.reg
  Aggiunge 'Apri con Freebuff':
  - Tasto destro su una cartella
  - Tasto destro su uno spazio vuoto dentro una cartella

Il comando avviato:
cmd.exe /c cd /d "<folder>" && <user-home>\freebuff.exe

Remove_Freebuff_Context_Menu.reg
  Rimuove le voci.
